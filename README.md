## About Me

I am a full stack developer and educator focused on making web development accessible to beginners. I built and run [CodeWithBhurtel](https://codewithbhurtel.com), a free learning platform covering HTML, CSS, and JavaScript through structured lessons, live coding challenges, and real-world projects.

Alongside the platform, I create technical content on YouTube and TikTok under the same brand, with a focus on creative front-end development, JavaScript animations, and project-based learning.
